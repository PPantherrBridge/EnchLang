Why EnchLang?

Standard programming languages treat mathematics as a second-class citizen. EnchLang is built for pure mathematicians and theoretical researchers who need a tool that speaks their language—sets, domains, and relations—natively.

Math-Native

No more `Math.pow(x, 2)`. Just write math. Domain violations are caught at runtime with meaningful mathematical errors.

Symbolic

First-class support for symbolic definitions, sets, and matrices. Think in abstractions, not implementation details.

Academic

Designed for clarity and proof verification, not for building web servers or system drivers.

Native Syntax

Write code as you write proofs. EnchLang supports domain constraints, set theory, and symbolic math out of the box.

>_ Numbers & Domains
x = 5            → integer
x : N = 5        → natural numbers
x : Z = -3       → integers
x : R = 2.7      → real numbers
x : C = 3 + 2i   → complex numbers
Strict domain typing ensures mathematical correctness.
